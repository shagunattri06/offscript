# 🛍️ OFFSCRIPT – Gen Z Y2K Cyber-Fashion E-Commerce Website

OFFSCRIPT is a web-based fashion e-commerce platform inspired by Gen Z streetwear, Y2K aesthetics, and futuristic cyber-fashion culture.

## Project Overview

OFFSCRIPT is designed to provide a modern and engaging online fashion shopping experience. The website combines bold visuals, curated fashion collections, editorial imagery, and interactive shopping features to create a distinctive digital storefront. Its design reflects contemporary youth fashion trends while offering an intuitive interface for exploring products and collections.

## Project Objective

The main objective of OFFSCRIPT is to develop a visually appealing, user-friendly, and interactive fashion e-commerce website that showcases modern Gen Z and Y2K-inspired clothing. The project aims to demonstrate frontend development skills using HTML, CSS, and JavaScript while implementing essential shopping interface features such as product browsing, quick view, cart management, and wishlists.

## Features

### Shopping Experience
- Browse fashion products through a dynamic product grid.
- Explore curated fashion collections.
- View product details using the quick-view interface.
- Add products to the shopping cart.
- Save favorite products to the wishlist.

### Interactive UI
- Modern Gen Z and Y2K-inspired design.
- Responsive layouts and smooth animations.
- Interactive collection tabs.
- Fashion editorial and campaign sections.
- Cart and wishlist drawers.
- Toast notifications for user interactions.
- Newsletter subscription interface.

## Tech Stack 💻

**Frontend:** HTML5, CSS3, JavaScript

**Styling:** Custom CSS, Flexbox, CSS Grid, Animations and Transitions

**Interactivity:** Vanilla JavaScript

**Tools:** Visual Studio Code, GitHub
